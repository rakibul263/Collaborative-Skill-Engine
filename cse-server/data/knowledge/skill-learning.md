# Skill Learning Playbook

## Skill levels (platform-aligned)
- **Beginner**: syntax, guided tutorials, clone projects
- **Intermediate**: build features independently, debug API integration
- **Advanced**: optimize, test, document tradeoffs
- **Mastery**: teach others, design systems, review architecture

## Learning a new skill in 4 weeks
- Week 1: official docs + 10 small exercises
- Week 2: mini feature in existing project (e.g., add chart to dashboard)
- Week 3: standalone micro-project showcasing the skill
- Week 4: refactor + write blog/README explaining decisions

## JavaScript ecosystem
- Master one framework deeply (React) before chasing every meta-framework
- Learn Node + Express alongside React for full MERN fluency
- TypeScript: adopt after comfortable with JS patterns

## Soft skills for collaboration platforms
- Write clear connection requests referencing shared skills
- Rate mentors fairly with constructive comments
- Maintain conversation context—summarize goals before asking for help

## Recommended next skills by goal
- **Frontend Developer**: TypeScript, testing, accessibility, performance
- **Backend Developer**: auth hardening, indexes, API design, observability
- **Full-stack**: deploy pipeline, one cloud provider, basic Docker
- **Data track**: SQL, Pandas, one ML project with evaluation metrics
- **DevOps track**: Docker, CI, monitoring for existing MERN app

## Project ideas tied to skills
- Add AI career advisor (RAG + user profile) — full-stack + ML literacy
- Improve mentor matching with explainable match scores
- Chat analytics: response time, topic tags from messages
