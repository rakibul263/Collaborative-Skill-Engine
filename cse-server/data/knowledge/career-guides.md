# Career Guides for Tech Learners

## Choosing a direction
- Map **teachSkills** (strengths) vs **learnSkills** (growth) to role families: Frontend, Backend, Full-stack, Data, DevOps.
- Align **teachLevel** and **learnLevel** (Beginner → Mastery) with project difficulty and mentor expectations.
- Use education and portfolio to signal credibility; supplement with GitHub and live demos.

## Job search strategy
- Target roles where your teach skills overlap job requirements; use learn skills as upside narrative.
- Network via mentorship platforms: offer help in strong skills while learning weak areas.
- Prepare STAR stories from collaborative projects (matching, chat, ratings).

## Skill gap analysis method
1. List target role required skills (from job posts or roadmaps).
2. Mark owned (teach), learning (learn), missing.
3. Prioritize gaps that unblock portfolio pieces in 2–4 weeks.
4. Pair each gap with one course module + one project task.

## Learning habits
- 70% building, 20% reading docs, 10% community (mentors, peer review).
- Ship weekly: small PRs, demo links, changelog in README.
- Request feedback from mentors on code structure, not just syntax.

## Bangladesh / university context
- Leverage university projects (e.g., Daffodil International University) as case studies.
- Contribute to open source or local hackathons for visibility.
- Balance FYP deadlines with portfolio polish—one flagship app beats five half-done repos.

## Using mentorship effectively
- Come with specific questions: "Review my React state design" vs "teach me everything."
- Match mentors whose teachSkills cover your top 3 learnSkills.
- Follow up with implemented feedback to build reputation on the platform.
