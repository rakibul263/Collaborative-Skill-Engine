# Frontend Developer Roadmap

## Foundations
- HTML5 semantic structure, accessibility (ARIA, keyboard nav)
- CSS: Flexbox, Grid, responsive design, Tailwind or modern utility workflows
- JavaScript ES6+: async/await, modules, closures, event loop

## Core stack
- React (components, hooks, context, performance)
- TypeScript for scalable apps
- React Router for SPA navigation
- State: Context, Zustand, or Redux Toolkit when complexity grows

## Styling & UX
- Tailwind CSS, component libraries (shadcn/ui)
- Framer Motion for micro-interactions
- Design systems, dark mode, responsive SaaS layouts

## Tooling
- Vite, npm/pnpm, ESLint, Prettier
- Git workflow, code review habits
- Testing: Vitest, React Testing Library, Playwright for E2E

## Intermediate → job-ready
- REST API integration, auth flows (Firebase/OAuth)
- Performance: lazy loading, memoization, bundle analysis
- SEO basics, meta tags for marketing pages
- Deploy: Vercel, Netlify, CI/CD basics

## Portfolio projects
- Skill-matching or mentorship dashboard (like Collaborative Skill Engine)
- E-commerce UI with cart and checkout mock
- Real-time chat UI with Socket.io
- Admin analytics dashboard with charts

## Career milestones
- Junior: ship 2–3 polished React apps with README and live demo
- Mid: lead feature slices, write tests, mentor juniors on CSS/React patterns
- Senior: architecture, design systems, accessibility audits, cross-team API contracts
