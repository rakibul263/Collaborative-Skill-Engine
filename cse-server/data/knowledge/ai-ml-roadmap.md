# AI/ML & LLM Roadmap

## Foundations
- Python programming, NumPy, Pandas
- Linear algebra, calculus, probability basics
- Data preprocessing, feature engineering
- Exploratory data analysis (EDA) workflows

## Machine Learning
- Supervised learning: regression, classification, ensemble methods
- Unsupervised learning: clustering, dimensionality reduction
- Model evaluation: cross-validation, metrics (precision, recall, F1, ROC-AUC)
- Scikit-learn ecosystem

- Neural networks fundamentals, backpropagation
- CNNs for computer vision basics
- RNNs, LSTMs for sequence data

- Text preprocessing, tokenization, embeddings
- Transformers architecture overview

- LangChain framework: chains, agents, retrievers

- RAG architecture: retrieval, augmentation, generation
- Prompt engineering: system prompts, few-shot, structured output
- Document chunking strategies (RecursiveCharacterTextSplitter)
